# 网页适配说明

默认基于 `assets/template/index.html` 制作，不引入框架、后端、地图 API 或必须联网的依赖。模板里六个中性章节、四段路线和旗子只是结构示例，没有真实行程。复制后按用户行程增删，不能只改文字、保留错位的旧路线。

## 先读这些代码位置

用关键字查找而不是依赖行号：

| 位置 | 作用与同步要求 |
| --- | --- |
| `.info`、`.day`、`.day-inner` | 右侧章节；保留编辑器依赖的类和唯一 ID |
| `MAP_PLACES` | 地点、坐标、标签偏移、可选插画 |
| `.route-leg` / `.route-leg-under` | 路线与底描；数量、顺序、路径一一对应 |
| `waypoints` | 到达节点坐标和所属路线索引 |
| `segments` | 章节 ID、路线索引、镜头、交通工具、标题映射 |
| `renderLabels()` | 地图坐标投影到屏幕文字层，字号不跟着镜头缩小 |
| `buildTimeline()`、`renderCamera()` | 滚动推进、镜头与移动载具 |
| `showOverview()` / `closeOverview()` | 展开与恢复，全图边界按新地图内容调整 |
| `window.__tripBaseMapSvg`、`snapshot()` | 保存原始地图骨架，重开后重建动态元素 |
| `TRIP_DRAFT_KEY` | 不同作品使用独立草稿键；创建脚本已生成随机项目标识 |
| `FALLBACK` | file:// 下照片候选文件名；只列右侧照片，不混入地点插画 |

## 地图模式与工作量

先读取用户选择及 `materials/journey.md`；没有明确要求地理比例时，按 SKILL.md 提供一次选择，不自作主张升级为精确测绘。用户说“真实地点”通常是要用自己的实际目的地，不等于要求真实距离比例。

### schematic：旅行示意地图（推荐）

- 模板画布为 1200 × 1600。先整理地点的大致东南西北、沿海/内陆关系、旅程先后，用画布上的 `x/y` 直接布局。这些是排版坐标，不是经纬度，不需要先建立经纬度表或距离矩阵。
- 可拉开相邻景点、压缩长途空白、简化海岸与山体轮廓，为插画和标签留空间。保持基本方位和拓扑关系：内陆点不画到海上、北南不倒置、陆路不穿海；不要求公里数或比例尺正确。返程或折返按用户行程保留，不能为画面顺滑改旅行顺序。
- 不逐点测量离海岸多少公里，不计算点间真实间隔、驾驶里程或用时，不下载 GIS 边界或精描海岸线。仅为消除地点重名、方向不明或海陆关系冲突进行必要查询；查清即可回到制作，不顺便扩展成全面地理研究。
- 已有坐标可以辅助判断，不必重查；不能把坐标齐全作为开工条件。地点关系清楚、标签不遮挡、路线对应即可进入插画阶段，不反复优化距离误差。
- 路线作为章节之间的示意连接；这是内部制作规则，不在展示页面添加比例或道路准确性说明。示意模式的插画质量与地理比例模式相同。

### geographic：实际地理比例地图（耗时较长）

- 仅在用户明确选择后使用。优先用用户提供的坐标或已有可靠数据；对缺少的地点坐标按需核实，记录来源并复用，避免因调整标签而反复查询。
- 使用适合覆盖区域的统一投影/映射放入画布，保留位置与相对间距；不要分别拉伸横纵轴或为了避让移动真实地点锚点。底图与地点使用同一坐标基准，插画和标签可偏移并用引线相连。
- 坐标到画布的映射本身即可决定间隔，无需额外计算所有点对距离、距海岸距离或驾驶用时。用户没要求实际道路时，用示意连线；记录在制作文档中，不在展示页面加技术说明。
- 确实需要真实道路、精确里程或可导航地图时，单独澄清数据要求与工具条件，不默认把所有这类工作加入本模式。缺少可靠数据或工具时说明具体缺口，不能猜坐标却声称精确，也不擅自改为示意模式。
- 远距离行程与局部密集景点并存时，优先用镜头缩放或明确标识的局部放大图，避免为一张等比例全图无休止微调。

### 已经制作中的项目

用户切换到示意模式时，保留可用的路线、插画、章节和已有数据，停止后续精确地理计算，只调整影响可读性的布局。不重做已经正常的部分。记录模式变化，后续恢复会话沿用该选择。

## 坐标和图层

大陆、城市、山地等行程应有相应地形，不能因为参考海报是海岛就把所有目的地画成岛。先按上述模式安排位置，再处理图层；生图模型只负责景物素材，不负责计算点位。

从底到顶：底色与低对比纹理 → 地形 → 地点插画 → 路线与节点 → 载具；地名在独立屏幕文字层。插画写入 `MAP_PLACES`：

```js
{
  id: 'stop-a', name: '目的地 A', kind: 'main',
  x: 500, y: 600, dx: 24, dy: -45,
  art_required: true,
  art: ['map-art/stop-a.png', 405, 430, 190, 150]
}
```

`MAP_PLACES` 保留可静态读取的 JSON 数组写法（上例为字段示意，实际配置使用双引号），便于完成检查逐个核对插画。`kind:main` 默认需要插画，确认只作交通标记的点可设置 `art_required:false` 并在制作记录中说明。

`x/y` 是路线锚点；`art` 后四项是图片在地图坐标里的左上角与尺寸；`dx/dy` 是屏幕像素级标签偏移。模板已支持 `art`：有图显示图，无图显示占位旗子。图片始终在地图坐标系中随镜头移动，不能放成不跟随地图的绝对定位网页贴纸。标签避让要兼顾所有插画；默认排布仍应人工检查，不能只相信自动碰撞逻辑。

## 章节、路线、镜头一起改

- 每个 `segments[].ids` 必须对应实际存在的章节，路线索引不得越界。
- 首屏完整概览，开始滚动才向首站靠近；结尾回到概览。全图模式退出后恢复到当前阅读位置。
- 同地点停留：使用 `focus:{x,y,zoom,follow:0}` 和 `pause:true`；需要指定已到达路线时用有效 `leg`，不要为停留编造交通路线。
- 模板仅有飞机和船。自驾、火车、步行等按用户行程补相应载具并同步切换逻辑；不得让船行驶在陆地上。载具用小型 SVG 合理，不必生图。
- 模板目前按首尾路线显示虚线；如果首尾不是飞行，应改为根据交通方式决定线型，不能机械继承。
- 镜头取景包含当前插画、地名与前进方向。地点很密时先调布局和标签引线，不靠缩小字号解决。
- 新插画可能超出旧边界；首屏 `fitZoom()`、全图边界、概览中心和缩放同时调整。
- `updateMapChapter()`、概览文案、`snapshot()` 复位标题和地图导航都要换成用户项目内容，清除“示例”文案。
- `.map-caption #trip-dates` 只显示整个行程日期范围，不加旅行名称或技术说明。使用用户提供的日期；初始化填一次，章节切换、展开全图、保存重开均不覆盖。创建脚本可用 `--dates` 传入已确认的日期文字。

## 编辑和保存的不变量

封面 `.hero-frame` 必须保留替换入口；正文 `.shot` 保留替换/删除。`#editor-hint` 仅编辑时显示完成与保存的区别，导出时随编辑工具栏清除，重开后正常重建。

保持 `.info` 与地图分开，编辑器只编辑右侧。导出时保留用户图文，清除运行时按钮、contenteditable、动画状态、临时标签和重复节点；地图还原为完整原始路线。地图结构修改必须进入 HTML/初始化配置，不要只在预览 DOM 中操作，避免保存后消失。

照片相对路径统一为 `photos/文件名`；`FALLBACK` 只登记真实照片。模板每次打开选图窗口时合并已引用照片与可读取的目录列表并去重，不永久缓存旧列表。新照片从电脑选过后，保存重开也应可在候选列表找到。文件名含空格、中文时正确编码，禁止写入绝对本机路径或仅当前会话有效的 blob URL。复制件改名时同步全部引用，不改用户原照片。浏览器 localStorage 是草稿，不是交付文件。验证导出时用新浏览器上下文或清理测试草稿，避免旧草稿掩盖保存失败。

保留字体文件及第三方许可，本地 vendor 保证双击打开可用。不从参考源码引入在线字体或地图外链。打开用户已有项目时先备份；新项目无需复制作者原版手账或示例行程。

模板结尾的 `.template-credit` 默认保留「手账模板与 Skill 制作：阿蓝蓝」以及 ScrollMap 原作者和来源链接。改写结尾章节时一并带上；这是工具来源署名，不是旅行作者或旅伴，不要写入用户的故事、照片说明或个人签名。用户如要求调整其显示方式可按要求处理，第三方许可文件继续保留。

## 素材分区与占位图

- `photos/`：仅当前用户的旅行照片/GIF。没有照片时允许为空；原片备份保留在另处，不自动复制进选图目录。
- `assets/photo-placeholder.svg`：全书唯一通用照片占位图，重复引用同一文件。可以只修改标题为这次旅行名称，不生成 day-1、day-2 或地点专属版本。已接入实拍的区域移除对应占位引用。
- `map-art/`：地图插画；不出现在照片选择器。兼容旧版 photos/map-* 引用，但新作品优先使用独立目录。
- 选图窗口过滤占位素材和地图插画；无实拍时展示“还没有旅行照片”的提示及选择按钮。不能把模板抽象 SVG 称作往年/其他目的地实拍。
- 双击 file:// 打开时不能扫描目录；说明只显示已登记照片。新照片先复制，再通过按钮选择。文件名用 encodeURIComponent，避免 #、? 被解释成 URL 片段或查询。
- 不删除用户原照片；更新既有项目时仅在副本中合并已识别的生成占位图、修改其引用，并保留原版本备份。

结构确认后的点位数、正文章节数分别记录。地图导航不必给每个次要景点一个按钮；在电脑浏览器检查实际导航占用区域与地图可见面积。
